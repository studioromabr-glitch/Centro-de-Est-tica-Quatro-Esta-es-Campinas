# Centro de Estética Quatro Estações
Site em React, TypeScript e Vite. Requer Node.js 22.12 ou superior.

## Desenvolvimento
npm install
npm run dev

## Cloudflare Pages
- Branch: main
- Framework: React (Vite)
- Build command: npm run build
- Build output directory: dist
- Root directory: vazio (raiz do repositório)
